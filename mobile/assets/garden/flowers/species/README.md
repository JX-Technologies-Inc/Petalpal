# Garden-adapted art slots

No production art exists in these slots yet. The authoritative slot paths, metadata and approval states are in `mobile/src/components/garden/flower-visuals/gardenArtManifest.json`.

See `docs/flower-visuals/FLOWER_GARDEN_ART_PRODUCTION_SPEC.md` for import and review steps and `FLOWER_GARDEN_ART_PROMPTS.md` for external art prompts. Create the species/base directories named by the manifest when delivering files. Never copy source botanical images into these slots or mark them approved automatically.
