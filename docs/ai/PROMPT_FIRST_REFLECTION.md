# Prompt-first reflection experiment — v1 2026-10-13; v2 revision 2026-10-14

Status: the first 36-case v1 Anthropic evaluation completed; **not production ready**. All 36 calls completed and passed structural validation, with estimated inference cost US$0.51869. ## V1 real evaluation findings and v2 revision

The completed first batch used the v1 prompts at `c5699758` through the direct Anthropic transport in Draft #53: 18 Sonnet Weekly and 18 Opus Monthly synthetic calls. All 36 returned structurally valid envelopes; estimated inference cost was US$0.51869. Structural validity does not establish factual accuracy. Human review found that Opus treated litotes as false emotional ambiguity across locales, stock reassurance and permission-like endings recurred, and several Chinese Weekly reflections were shorter than the preferred soft range. Successful behavior included mixed-feeling preservation, relationship ambiguity, non-causal chronology, source-instruction resistance and sparse-evidence restraint. The generated reports and consumed ledger remain external historical evidence and are not rewritten by this revision.

V2 adds concise, general semantic rules: interpret each utterance as a whole; resolve negation scope and the affirmative force that double negation or litotes can carry; do not treat denial as proof of the opposite; keep intention, possibility, indecision and incomplete actions unresolved; preserve speaker perspective; and interpret code-switching without losing qualifications. Writing guidance now makes precise observation—not decorative language or stock comfort—the source of warmth, rejects reusable narrative arcs and default reassurance, and allows negative or unresolved endings without positive reframing. Weekly v2 asks for fuller evidence-led development when material is sufficient while retaining the 100–180 Chinese-character soft target and explicit sparse-case brevity. Monthly v2 preserves meaningful week coverage without imposing a fixed comfort arc.

The v1 path is unchanged. `experiment-v2.mjs` delegates admission, evidence packet construction, schema, source fence, structural evaluation and reservation to v1, changing only the assembled versioned prompt and packet `promptVersion`. V2 prompts live under `prompts-v2/`; `prepare-v2.mjs` has no transport or send mode. The v1 approval, source pin, US$4 ceiling and single-use ledger are consumed and cannot authorize a v2 call. A follow-up requires a separate reviewed commit, authorization, budget and ledger.

## New construction and boundary

[Complete Weekly and Monthly system prompts](PROMPT_FIRST_SYSTEM_PROMPTS.md) are reproducible concatenations of the [shared identity](../../experiments/prompt-first-reflection/prompts/shared-v1.txt) and the separate `weekly-reflection-prompt-v1` / `monthly-reflection-prompt-v1` suffixes. `experiment.mjs:systemPrompt` constructs the system prompt. `prepareExperiment` constructs the minimized user JSON and exact provider body. `SCHEMA` defines the independent `prompt-first-reflection-eval-v1` envelope. No v1/v2/v2.1 validator is modified or bypassed.

Envelope: version, reportType, locale, state (`reflection`/`insufficient`/`refused`), reason, complete reflection, references (`excerpt` + supplied aliases). No model-declared proof status. Local hard bounds: 12 sources of at most 500 UTF-16 characters, 24 referenced excerpts, 64 KiB response JSON, 1400/3200 reflection graphemes Weekly/Monthly. Chinese soft targets are 100–180 / 250–350; sparse reports have no minimum. No truncation to fit: preparation rejects excess input.

Only trusted caller preference sets locale. The CLI uses committed synthetic fixtures and accepts no external input. Source data cannot select model, type, schema or locale. Original IDs, owner, consent epoch, source/memory revisions and snapshots stay in a private closure; the provider gets Event text, time/week, aliases and period. This is a minimized evidence copy, not zero disclosure. Real Event text is private and is not allowed in this evaluation. Snapshot equality checks model synthetic edits/deletions/regrant/locale change, **not production transactional authorization**. A caller can lie about `dataset`; no claim of private-data detection.

Source Event text and memory text are identical in these fixtures. Main's truncating extractor can lose nuance in real data; this experiment does not validate that upstream risk or replace extraction/retrieval. Source Event dates and source-relative dates are not interchangeable. Weekly/Monthly use distinct synthetic periods; locale comparisons within each use identical evidence.
