## 第一部分：内测用户须知（发给用户）

### 欢迎来到 PetalPal 内测 🌸

PetalPal 把你每天的小事和心情变成一座会长大的花园。感谢你帮我们试用！这是**内测版**，可能会有小问题，你的反馈
会直接影响正式版。

### 怎么进入

1. 打开 **https://app.jastrevia.com**
2. 第一次会看到一个邮箱验证页面（Cloudflare Access）：输入你收到邀请的邮箱，填写邮件里的验证码。
3. 进入后注册 PetalPal 账号，验证邮箱，就能进入你的花园。

手机和电脑浏览器都可以用。`[待确认：是否有 iOS 内测版（TestFlight）]`

### 可以试试这些

- **写一个 Event**：记下今天的一件小事，选一个心情（晴朗、温柔、安静、疗愈、火焰、好奇、迷茫、平静），花园里就会种出一朵花。也可以用语音输入。
- **看看你的花园**：你写的每一条都会变成花园里的一朵花，小仙女会在花园里陪你。
- **每周回顾**：写满一周后，下周一起可以在树屋里的 Reflection 生成「上周回顾」。它只根据你写下的内容整理，不会替你下结论。
- **好友** `[待确认：内测是否开放好友和拜访]`：加好友后可以去对方的花园看花。好友只能看到花，看不到你写的文字。

### 你需要知道的

- **你的记录是私密的**：只有你自己能看到你写的 Event 和回顾。
- **AI 是可选的**：在 Settings 里可以随时打开或关闭。打开后，你写的 Event 文字和你提交的语音会发送给 Cloudflare Workers AI，或经 Cloudflare AI Gateway 发送给 Anthropic，用来生成心情建议、语音转写和每周回顾。处理可能在你所在国家以外进行。关闭后不会再发送新的内容，但已经发送的无法撤回。详细说明在 App 内的 AI 说明页。
- **PetalPal 不是医疗或紧急服务**。如果你或身边的人有危险，请立即联系当地紧急服务或你信任的人。
- **内测数据**：`[待确认：内测结束后数据是否保留、是否可能重置；如可能重置，我们会提前通知]`
- **删除**：你可以随时删除某条记录，或在 Settings 里删除整个账号。

## 第二部分：反馈表问题（放进 Google 表单或问卷工具）

1. 你用的设备和浏览器？（iPhone Safari / Android Chrome / 电脑 Chrome / 电脑 Safari / 其他）
2. 你用了哪些功能？（多选：写 Event、语音输入、花园、小仙女、每周回顾、好友）
3. 整体感受打几分？（1–5）
4. 写 Event、种花的过程顺不顺？哪里卡住了？
5. （用过每周回顾的）回顾里的内容是不是都来自你写的？有没有写错或编造的地方？（是都准确 / 有小错误 / 有编造）请描述，不必贴原文。
6. 回顾读起来感觉怎么样？（太长 / 刚好 / 太短；像真人 / 像 AI）
7. 有没有遇到 bug？在哪个页面、做了什么、看到了什么？
8. 有没有让你不舒服或担心隐私的地方？
9. 你最喜欢的一点和最想改的一点？
10. 你愿意继续用吗？（会 / 可能 / 不会）
11. 可以联系你做简短回访吗？（可以，留邮箱 / 不用了）
