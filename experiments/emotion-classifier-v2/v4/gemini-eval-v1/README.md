# Gemini evaluation v1

This directory is reserved for a **human-written, Gemini-annotated / Gemini-adjudicated evaluation**.

`protocol.json` was locked before cohort selection, annotation, labels, and candidate inference. Candidate predictions, probabilities, metrics, thresholds, training results, and Codex/Astra label suggestions are prohibited from every Gemini annotation request. Once `lock.json` exists, references are immutable; model errors may not cause relabeling.

The reference is not human-gold and must never be described as human-labeled.
