# 长裙 Fairy 六帧测试报告

**处理与播放测试已完成；清晰左右交替步态验收未通过。没有重新设计或补画动作。**

唯一素材来源是本次上传的 1672×941 长裙六帧图。Downloads 中的 HTML/GIF 仅作为已提供的审阅参考，不作为替代素材。未使用短裙图、旧骨骼、Spine、Blender 或旧 walk 资产。

| 检查项 | 结论 |
|---|---|
| 1. 帧提取 | 六帧原底色 PNG，统一 400×720。仅整数平移对齐；无独立缩放、旋转、变形。源图所属区域像素逐一验证不变。原底色版保留对应原标签。 |
| 2. 透明抠图 | 六张 RGBA 候选已导出，去掉纸面、标签及连续地面线。采用局部底色估计、背景连通区域、已知负空间、窄边缘遮罩和去底色；不是全图删除白像素。RGB 源无法提供原始 alpha，翅膀透光为保守估算。深色底仍可看出部分发丝/浅色裙缘的亮边；鞋与地线交界不能保证像素级恢复。不能标记为最终生产透明素材。 |
| 3. 行走可读性 | 上身安静直立、长裙和手臂变化克制，但循环更像重复的后脚抬起/放下，缺少清晰完整换步。 |
| 4. 左右腿交替 | 未通过。1/4 的接触构图非常接近，2/5 的抬脚关系也相似；画面前方鞋持续占据前方，长裙遮住了腿根，无法据此可靠确认解剖左右身份交换。标签不是证据。 |
| 5. 地面滑动 | 水平测试有滑步风险且不能通过锁地验收。前方鞋在 1→3 与 4→6 的相对位移、重置并非一个已验证支撑脚轨迹。页面速度是独立测试参数，不会伪造脚锁地或偷偷挪动单帧来掩盖问题。 |
| 6. 第 3/6 帧 passing | 两帧均表现为后方脚抬起、另一脚留在前方；没有清晰展示相反腿越过支撑腿的结构。两帧需要原画层面的动作澄清，单纯裁切/透明化无法修复。 |

## 哪些帧需要纠正

- **3、6：主要问题。** 需要真正相反的 passing 关系；当前并不能读出哪一条腿在分别通过。
- **1、4：需一起核对。** 应形成相反接触腿的可见线索，目前轮廓非常近似。
- **2、5：需随接触腿一起核对。** 当前更像同一抬后脚结构的轻微变化。
- 长裙仍遮住膝部，没有为了显示腿而改短裙子。没有镜像、倒放、重排、插入重复帧、交叉淡化或 AI 补帧。

## 文件与使用

- `original/frame_01.png` … `frame_06.png`：原底色、源像素裁切。
- `transparent/frame_01.png` … `frame_06.png`：透明候选；画布和注册与原底色版相同。
- `index.html`：用浏览器打开。支持播放/暂停、上/下一帧、速度、循环、原图/透明切换、深浅背景和水平移动。
- `review/long_skirt_walk.gif`：6 帧、每帧 200 ms、1.2 秒循环。
- `review/long_skirt_walk.png`：透明 APNG，时间与 GIF 相同。
- `review/transparent_contact_sheet.png`：六帧并排。
- `review/alpha_background_checks.png`：深浅底检查。
- `frames.json`：固定顺序、原图哈希、整数对齐偏移。
- `validation.json`：技术验证结果。

透明图中的 RGB 在半透明边缘经过底色反解，因此不能声称每个 RGBA 值都等于原 RGB 图；不透明内部色差验证为至多 1/255。深浅底检查比黑底 PNG 缩略图更适合判断实际边缘。
